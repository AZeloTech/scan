# Fixture provenance

Every binary fixture in this directory needs a row here naming the script and the
seed that generated it. A fixture without a row fails the PII guard.

**No fixture may be derived from a photograph of a real document.** Not cropped,
not blurred, not redacted. Fixtures are generated from scratch by scripts in this
repository, using only the fictional personas below.

Personas allowed in fixture text: Joao Azelo, Maria Azelo, CPF 000.000.000-00.

## How to add one

1. Write or extend a generator under `scripts/` that renders the page from text
   and shapes, never from a photo.
2. Run it with a recorded seed so the output is reproducible.
3. Add the row above in the same commit as the binary.
